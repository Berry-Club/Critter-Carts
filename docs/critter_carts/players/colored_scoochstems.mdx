# Colored Scoochstems

Colored Scoochstems route [Scoochworms](@critter_carts:scoochworms) according to their color. They are useful for building several routes that cross or branch without sending every Scoochworm down the same path.

Colored Scoochstems are available in six colors:

- Green
- Blue
- Red
- Yellow
- Purple
- Cyan

## Routing

A Scoochworm can travel on a Colored Scoochstem only when the Scoochworm and stem have the same color. To a Scoochworm of any other color, that stem is not a valid route.

Ordinary [Scoochstem](@critter_carts:scoochstem) accepts Scoochworms of every color. Place Colored Scoochstems beside ordinary Scoochstem to create color-selective branches. When choosing its next valid path, a Scoochworm ignores every branch whose color does not match its own.

For example, a junction with a Red Scoochstem on one branch and a Blue Scoochstem on another sends red Scoochworms onto the red branch and blue Scoochworms onto the blue branch. Other colors cannot use either colored branch.

## Changing a Scoochworm's Color

Sneak-use a Scoochworm's head to cycle its color. The color order is green, blue, red, yellow, purple, cyan, and then green again. The head and every body segment change together.

A Scoochworm remembers its color when the world is saved and keeps that color when split with shears. Both Scoochworms created by the split have the original color.

## Building Routes

Colored Scoochstems support travel on every face, allowing matching Scoochworms to move across floors, walls, and ceilings. Unlike ordinary Scoochstem, individual faces cannot be disabled with an axe.

Use ordinary Scoochstem for shared sections of a route and Colored Scoochstems only where paths need to be separated. Make sure each color has a valid continuation: a Scoochworm stops if none of the available stems match its color.
