A **Spider Nest Interface** tells the spiders in a [Hopping Spider Nest](@critterworks:hopping_spider_nest) how to use an inventory connected to [Web Lines](@critterworks:web_lines).

Use the interface in your hand to configure its color, direction, priority, and optional [Item Filter](@critterworks:item_filter). Then use it on a Web Line endpoint attached to the inventory. Sneak and interact with the installed interface using an empty hand to remove it.

Interact with an installed interface to change its settings.

## Settings

**Input** inventories supply items to the network. **Output** inventories receive them. Spiders only carry items between interfaces with the same color.

An Item Filter limits which items an interface can supply or receive. Without a filter, it accepts every item.

Priority controls which work is chosen first. Higher numbers are preferred. Input priority is considered before output priority.

The interface uses the inventory on the block face where its Web Line endpoint is attached. Make sure the inventory can be accessed from that side.
